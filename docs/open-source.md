# Open-source stack

*Polymer Neural Nets, version 1.0.0 (17 November 2026)*

Every dependency is open source. The project itself is CC BY-NC-SA 4.0.

| Package | Role | License |
|---|---|---|
| [PyTorch](https://github.com/pytorch/pytorch) | tensors, autograd, training | BSD-3-Clause |
| [PyTorch Geometric](https://github.com/pyg-team/pytorch_geometric) | `MessagePassing`, `Data`, `DataLoader` | MIT |
| [OpenMM](https://github.com/openmm/openmm) | reference MD, learned-force MD | MIT (API) / LGPL (CUDA, OpenCL platforms) |
| [NumPy](https://github.com/numpy/numpy) | arrays | BSD-3-Clause |
| [SciPy](https://github.com/scipy/scipy) | fits, KS and Wasserstein tests | BSD-3-Clause |
| [SymPy](https://github.com/sympy/sympy) | symbolic derivations in notebooks 00 and 01 | BSD-3-Clause |
| [pandoc](https://github.com/jgm/pandoc) and XeLaTeX | the PDF editions of the notebooks | GPL-2.0 / LPPL (tools only, not distributed) |
| [Matplotlib](https://github.com/matplotlib/matplotlib) | figures | PSF-based (Matplotlib License) |
| [ReportLab](https://www.reportlab.com/opensource/) | building `REFERENCES.pdf` | BSD |
| [pytest](https://github.com/pytest-dev/pytest) | tests | MIT |
| [Jupyter](https://github.com/jupyter) | notebooks | BSD-3-Clause |
| [uv](https://github.com/astral-sh/uv) | environments | MIT / Apache-2.0 |

Optional, for the next stages: [e3nn](https://github.com/e3nn/e3nn) (MIT),
[MACE](https://github.com/ACEsuit/mace) (MIT), [NequIP](https://github.com/mir-group/nequip) (MIT),
[openmm-torch](https://github.com/openmm/openmm-torch) (MIT/BSD),
[LAMMPS](https://github.com/lammps/lammps) (GPL-2.0).
